Getting Started

Quick Start

Jalankan server lalu langsung gunakan. Semua endpoint di prefix /api.

# 1. Install dependencies
npm install

# 2. Jalankan dev server
npm run start:dev

# 3. Test health check
curl http://localhost:3000/api/health

# 4. Cari lagu di YouTube → CDN mp3 langsung
curl -X POST http://localhost:3000/api/youtube/search \
  -H "Content-Type: application/json" \
  -d '{"query":"Bohemian Rhapsody","format":"mp3"}'
